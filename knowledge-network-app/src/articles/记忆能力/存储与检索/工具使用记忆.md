# 工具使用记忆

## 一句话定义

记录「**在什么上下文下调用哪个工具曾成功/失败**」，用于少样本提示、路由与错误规避。

## 先理解什么（入门）

工具调用不仅是即时行为，也可沉淀为经验：某参数组合常超时、某 API 在夜间限流。此类记忆帮助规划层少踩坑。

## 再理解什么（进阶）

- **粒度**：按 `(tool_name, error_code, user_segment)` 聚合统计。
- **隐私**：工具入参可能含敏感数据，存储需脱敏或哈希。
- **衰减**：旧版本 API 经验在新版本可能有害，要绑定 API 版本号。

## 落地要点（实践）

- 与 tracing 系统打通，从 span 自动生成统计。
- 在 prompt 中注入「最近 3 条相关失败教训」即可，避免过长。
- 对自动建议的工具排序做 A/B。

## 常见坑

- 把偶然网络抖动当成工具缺陷永久写入。
- 记忆与权限模型脱节，泄漏他人调用记录。

# Token缓冲区

## 一句话定义

为即将进入模型或刚离开模型的文本**预留或计量**的 token 容量管理单元，用于平滑流式输出与削峰。

## 先理解什么（入门）

流式场景下，网络与 UI 需要缓冲；在 Agent 里更常见的是**预计算**：本步最多还能塞多少检索结果、多少工具 JSON。

## 再理解什么（进阶）

- **预检**：调用模型前用 tokenizer 估算总长度，超限则触发摘要或丢弃低优先级块。
- **动态预算**：简单任务少留 buffer，复杂推理多留思考空间。
- **流控**：对 SSE 下行做背压，避免客户端内存暴涨。

## 落地要点（实践）

- 监控 p95 输入长度，驱动索引 chunk 大小调参。
- 为工具输出设硬上限，并提供「展开全文」二次拉取。

## 常见坑

- 中英文混合导致估算偏差过大。
- 多模态 token 与文本 token 混算错误。

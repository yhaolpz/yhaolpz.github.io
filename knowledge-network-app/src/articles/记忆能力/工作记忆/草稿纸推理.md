# 草稿纸推理

## 一句话定义

为模型或 Agent 显式保留的**中间推理与工作笔记区**（scratchpad），用于分解子目标、记录假设与验算，不必全部展示给最终用户。

## 先理解什么（入门）

链式思考（CoT）可以只在内部写；Scratchpad 则是**可读写的外部记忆槽**，多步任务里常用来存「已尝试的方案」「待验证的假设」。

## 再理解什么（进阶）

- **可见性**：内部 scratchpad vs 对用户可见笔记要分离权限。
- **长度控制**：定期压缩或只保留关键结论回写任务上下文。
- **与工具联动**：可把中间 SQL/代码放 scratchpad 供下一步引用。

## 落地要点（实践）

- 约定格式（Markdown 小节 / JSON）以便解析。
- 防止将密钥、token 写入可持久化 scratchpad。
- 在评测中对比「有/无 scratchpad」的成功率。

## 常见坑

- Scratchpad 无限增长，检索与注入成本失控。
- 模型把草稿当最终答案输出，未做后处理过滤。

# 当前任务上下文

## 一句话定义

描述**本轮任务目标、输入工件、约束与进度**的紧凑状态，使模型不必从冗长闲聊中推断「现在在干什么」。

## 先理解什么（入门）

与完整对话历史不同，任务上下文强调「与完成工作直接相关的最小事实集」。适合工单、编程 Agent、数据分析等多步场景。

## 再理解什么（进阶）

- **状态机视角**：待办 / 进行中 / 阻塞 / 完成；每步记录依赖是否满足。
- **工件引用**：大文件只存 URI + 校验和，不存全文。
- **与 Scratchpad 分工**：Scratchpad 偏推理草稿；任务上下文偏业务字段。

## 落地要点（实践）

- 用 JSON schema 固定字段，便于程序校验与 UI 展示。
- 每步工具执行后更新「已完成 / 待完成」列表。
- 任务取消或切换时显式清空，避免脏状态。

## 常见坑

- 上下文里混着上一条无关任务的残留字段。
- 未记录失败原因，重试时重复踩坑。

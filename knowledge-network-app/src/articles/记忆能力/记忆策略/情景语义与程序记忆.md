# 情景语义与程序记忆

## 一句话定义

认知科学里常见的三分法：** episodic（经历性）、semantic（事实性）、procedural（过程性）**，映射到 Agent 即事件日志、知识事实、操作套路。

## 先理解什么（入门）

- **情景记忆**：「上周二谁改了配置」这类带时空的事件。
- **语义记忆**：「公司年假政策」这类不依赖具体经历的事实。
- **程序记忆**：「发布流程先跑 CI 再灰度」这类步骤型知识。

## 再理解什么（进阶）

- 不同记忆类型适合不同存储：事件 → 时序库/日志索引；事实 → 向量+图谱；流程 → 工作流模板库。
- **迁移**：多次成功执行同一流程可把轨迹提炼为 procedure。

## 落地要点（实践）

- 建模时显式标注记忆类型字段，检索策略分流。
- 程序记忆与 workflow 引擎版本绑定。
- 评测：跨类型问题是否路由到正确存储。

## 常见坑

- 把程序记忆写成自然语言段落，难以被机器逐步执行。
- 情景与语义混在同一向量空间导致检索混淆。

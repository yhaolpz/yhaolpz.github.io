# AutoGPT

## 一句话定义

早期开源「自主 Agent」代表之一：把目标拆成子任务并循环调用工具与模型，强调**自我驱动完成多步**（历史经典架构，适合理解演进脉络）。

## 先理解什么（入门）

AutoGPT 流行于 GPT-4 初期，展示了「目标 → 规划 → 执行 → 记忆」闭环的雏形，也暴露了成本高、易跑偏、难评测等问题。

## 再理解什么（进阶）

- **任务队列与优先级**：防止无限扩展子目标。
- **人类在环**：关键节点需审批，否则风险大。
- **与现代栈对比**：如今更常用 LangGraph、Agents SDK 等带检查点与观测能力的框架。

## 落地要点（实践）

- 若研究历史实现，关注其 memory 文件与 prompt 模板设计。
- 不要直接照搬生产；先做沙箱与小流量实验。

## 常见坑

- 让 Agent 无边界上网与执行 shell，引发安全事故。
- 无停止条件导致 token 烧穿预算。

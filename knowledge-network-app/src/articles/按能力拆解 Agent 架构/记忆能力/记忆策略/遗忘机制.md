# 遗忘机制

## 一句话定义

按策略**删除、降权或归档**不再有效或不应保留的记忆，防止画像偏见、合规风险与检索噪声。

## 先理解什么（入门）

遗忘不是 bug：人也会忘。系统需要 TTL、用户撤销、法规删除（被遗忘权）等机制。

## 再理解什么（进阶）

- **硬删除 vs 软删除**：合规常要求硬删除；分析场景可能软删除并打标。
- **衰减**：降低低使用频率记忆的向量权重，而非立即删除。
- **级联**：删用户要删其画像、索引、对象存储中的派生文件。

## 落地要点（实践）

- 产品设置里提供「清除我的 Agent 记忆」入口。
- 定期审计「最久未访问且高敏感」记录。
- 遗忘操作写审计日志（谁、何时、删了哪类数据）。

## 常见坑

- 向量库删了元数据还在另一张表，导致幽灵引用。
- 模型仍从缓存会话里「想起」已删记忆。

# BabyAGI

## 一句话定义

另一个早期自主 Agent 实验项目：通过**任务列表 + 优先级**驱动模型不断生成与执行子任务，用于研究「自我扩展任务栈」的行为。

## 先理解什么（入门）

BabyAGI 结构简单，便于教学：主循环创建、重排、执行任务。与 AutoGPT 一样，对今天的产品级 Agent 更多是**思想实验与反例来源**。

## 再理解什么（进阶）

- **任务爆炸**：若无约束，队列会生成低价值任务。
- **评价函数缺失**：早期实现弱依赖外部成功指标。
- **与现代规划模块对比**：层次规划、POMDP、RLHF 等更可控。

## 落地要点（实践）

- 读源码关注：任务存储结构、prompt 片段、停止条件。
- 做课堂演示时限制工具与白名单域名。

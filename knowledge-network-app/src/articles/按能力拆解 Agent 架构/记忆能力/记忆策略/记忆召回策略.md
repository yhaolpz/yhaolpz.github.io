# 记忆召回策略

## 一句话定义

在需要时从长期存储中**检索或拼装**相关记忆注入上下文，并控制噪声与延迟。

## 先理解什么（入门）

召回常与向量相似度、关键词、图谱一跳/多跳结合。Agent 要决定「要不要回忆」「回忆多深」。

## 再理解什么（进阶）

- **查询改写**：把当前 utterance 扩展成包含省略主语的完整查询。
- **混合检索**：BM25 + 向量，缓解专有名词召回弱的问题。
- **过滤**：按用户、项目、时间窗硬过滤，再做相似度。

## 落地要点（实践）

- 记录召回日志：query、topK id、得分，便于调参。
- 空召回时的 fallback：问用户、用全局默认、或仅依赖 RAG。
- 对高敏记忆二次鉴权后再注入。

## 常见坑

- TopK 过大把弱相关记忆全带进来引发幻觉。
- 忽略「遗忘」标记，召回已失效偏好。

# 用户画像

## 一句话定义

对用户偏好、角色、目标、历史行为的**结构化摘要**，用于个性化回答与默认选项，属于长期记忆的一种。

## 先理解什么（入门）

画像不是存聊天记录原文，而是「可复用的结论」：常用语言、职级、关注模块、禁忌话题等。要可解释、可撤回。

## 再理解什么（进阶）

- **合规**：GDPR/个人信息保护法下的同意与删除权。
- **漂移**：用户兴趣会变，需要置信度与时间衰减。
- **冷启动**：新用户用默认画像 + 主动询问补齐关键槽位。

## 落地要点（实践）

- 画像字段用 schema 固定，避免自由文本堆叠。
- 写入前做规则校验（年龄、地域等敏感字段）。
- 与 RAG 区分：画像关于人，知识库关于事。

## 常见坑

- 用单次对话错误推断长期偏好。
- 画像泄露给无权模型或日志。

# 知识库

## 一句话定义

企业或产品侧的**权威文档集合**（制度、FAQ、接口说明等），经索引后供 Agent 检索引用，是长期记忆的重要来源之一。

## 先理解什么（入门）

知识库强调「可信、可版本、可权限控制」。与互联网搜索不同，它回答的是「我们组织内部的事实」。

## 再理解什么（进阶）

- **版本与生效日期**：制度变更时要能回答「当时适用哪版」。
- **切片与溯源**：回答必须能回到段落或页码，便于审计。
- **多租户隔离**：索引与查询都要带租户/空间 id。

## 落地要点（实践）

- 接入 CI：文档合并后自动重建索引。
- 对 PDF/HTML/Markdown 统一管线，避免格式分叉。
- 监控「检索为空」与「低置信度」比例。

## 常见坑

- 把草稿与正式版混在同一索引未打标签。
- 未同步删除已下线文档，产生陈旧答案。

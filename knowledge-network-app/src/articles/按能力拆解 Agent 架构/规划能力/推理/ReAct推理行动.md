# ReAct推理行动

## 一句话定义

将**推理轨迹与外部行动**交替生成：思考 → 调工具 → 观察结果 → 再思考，适合需与知识库或环境交互的任务。

## 先理解什么（入门）

ReAct 把「只动嘴的 CoT」扩展为「能动手」：行动包括查百科、调 API、在模拟器中移动等。观察结果会写回上下文驱动下一步。

## 再理解什么（进阶）

- **动作空间设计**：动作过细则步数爆炸；过粗则难以纠错。
- **终止条件**：最大步数、无新信息、任务完成判定。
- **与函数调用 API 映射**：现代实现常用 tool_calls 代替自由文本动作。

## 落地要点（实践）

- 观察结果结构化（JSON）优于长自然语言。
- 记录每步 latency 与失败码，便于回放。
- 对高风险动作加人工审批节点。

## 常见坑

- 观察文本噪声大，模型被带偏。
- 无环检测导致循环重复同一查询。

# 思维链

## 一句话定义

通过提示模型**逐步写出中间推理步骤**（Chain-of-Thought），提升复杂算术、逻辑与多约束问题的正确率。

## 先理解什么（入门）

CoT 可以「零样本」（Let’s think step by step）或「少样本」（给推理示范）。它提高可解释性，但会增加输出长度与延迟。

## 再理解什么（进阶）

- **忠实性风险**：模型可能编造看似合理的中间步骤。
- **与工具结合**：推理到某步应触发计算器/代码执行，而不是纯口算。
- **自洽性**：可让模型对同一问题多次采样投票（Self-Consistency）。

## 落地要点（实践）

- 对需要严格格式的任务，要求「内部思考不输出」或改用 JSON mode。
- 在评测集上对比 CoT on/off 的准确率和成本。
- 对安全敏感场景审查中间步骤是否泄露隐私。

## 常见坑

- 过长 CoT 挤占工具结果与检索内容空间。
- 把 CoT 当万能药，忽略数据与工具质量。

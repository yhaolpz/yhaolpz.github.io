# 函数调用

## 一句话定义

让模型输出**符合 JSON Schema 的结构化参数**，由运行时映射到本地或远程函数，是 Agent 执行侧的核心集成方式。

## 先理解什么（入门）

函数调用把「自然语言意图」变成「可执行 API」。模型侧看到工具描述；执行侧负责鉴权、校验、真正调用。

## 再理解什么（进阶）

- **strict schema**：减少幻觉字段（视平台支持）。
- **并行调用**：只读工具可并行；写操作需顺序与幂等。
- **结果回注**：tool 消息必须带 call id，对话才能继续。

## 落地要点（实践）

- 工具描述写清输入输出、错误语义、速率限制。
- 对参数做服务端二次校验，不信任模型。
- 记录每次调用的延迟与返回大小。

## 常见坑

- Schema 过宽导致乱填；过窄无法表达业务。
- 未处理「模型声称调用但未实际执行」的中间人风险。

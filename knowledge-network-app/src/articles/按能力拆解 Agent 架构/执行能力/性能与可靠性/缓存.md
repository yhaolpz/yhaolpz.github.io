# 缓存

## 一句话定义

把昂贵计算或远程调用的结果**暂存**起来复用，降低延迟与费用，是执行层与模型层共同的优化杠杆。

## 先理解什么（入门）

缓存层级：浏览器、CDN、应用内存、Redis、结果数据库。Agent 场景常见：embedding、检索结果、工具输出摘要。

## 再理解什么（进阶）

- **TTL 与失效**：业务数据变更时要主动 purge 或版本键。
- **一致性**：读写穿透 vs 写回。
- **安全**：缓存键不可泄露敏感 token。

## 落地要点（实践）

- 对 LLM 响应按 `(model, prompt_hash, tools_version)` 键缓存。
- 命中率与脏读率监控。
- 大对象放对象存储，缓存里只存指针。

## 常见坑

- 缓存了含用户隐私的回答被其他用户命中。
- 无上限内存缓存 OOM。

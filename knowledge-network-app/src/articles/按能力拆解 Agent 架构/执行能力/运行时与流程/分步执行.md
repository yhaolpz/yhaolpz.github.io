# 分步执行

## 一句话定义

把任务拆成**顺序步骤**逐步执行，每步可检查前置条件与输出，是可靠自动化与 Agent 工作流的基础模式。

## 先理解什么（入门）

与「一次写完所有代码再运行」相对，分步执行便于插入日志、重试与人工确认。常与 DAG 或状态机结合。

## 再理解什么（进阶）

- **检查点**：每步成功后持久化状态，崩溃可恢复。
- **补偿**：某步失败时撤销已执行副作用。
- **与人协作**：某步需输入密码或审批时阻塞等待。

## 落地要点（实践）

- 每步定义输入/输出 schema 与超时。
- 用幂等 id 贯穿全链路。
- 可视化展示当前步骤与预计剩余。

## 常见坑

- 步骤间隐式共享可变全局状态导致不可复现。
- 无超时导致永远阻塞。

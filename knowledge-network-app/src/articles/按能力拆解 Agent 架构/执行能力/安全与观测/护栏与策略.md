# 护栏与策略

## 一句话定义

在输入、输出或工具调用前后运行**策略检查**（规则或小模型），拦截不安全、不合规或低质量内容。

## 先理解什么（入门）

Guardrails 可与业务规则（正则、字典）、分类模型、LLM-as-judge 组合。OpenAI Agents SDK 也提供 input/output/tool 三类护栏概念。

## 再理解什么（进阶）

- **延迟 vs 安全**：并行跑护栏降低时延；高危路径串行严格检查。
- **误杀率**：要监控 false positive 对业务的影响。
- **对抗**：护栏提示本身也可能被攻击，需多层防御。

## 落地要点（实践）

- 对支付、删除等操作强制二次确认或人审。
- 护栏失败要有用户可见原因码。
- 定期用红队样本集回归测试。

## 常见坑

- 只在入口检查，忽略工具返回中的恶意内容再入模。
- 护栏与主模型版本不同步导致策略漂移。

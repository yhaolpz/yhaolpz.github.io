# 调用链追踪

## 一句话定义

为一次 Agent 运行记录**跨服务、跨工具**的因果链（trace/span），用于排障、计费与质量分析。

## 先理解什么（入门）

OpenTelemetry 已成为事实标准：trace id 贯穿 LLM 调用、检索、工具、子 Agent。LangSmith、Arize 等也提供垂直方案。

## 再理解什么（进阶）

- **采样**：高流量下 tail-based sampling 保留错误 trace。
- **PII 脱敏**：span 属性默认不打原文用户输入。
- **与日志关联**：trace_id 写入应用日志。

## 落地要点（实践）

- 为每个 tool call、每个模型 generation 建 span。
- 设 SLO 看板：p95 端到端延迟。
- 长任务异步导出注意 `flush`。

## 常见坑

- span 过细导致存储成本爆炸。
- 上下文丢失导致无法串联子进程。

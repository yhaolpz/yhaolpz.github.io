# 文件系统

## 一句话定义

在限定根目录下**读写文件**，支撑代码生成、批处理、日志采集等 Agent 任务。

## 先理解什么（入门）

文件是最通用的数据交换介质。Agent 需要知道路径约定、编码、原子写入与锁。

## 再理解什么（进阶）

- **chroot / 容器**：把可见文件系统限制在项目目录。
- **大文件策略**：分块读、流式 hash，而非一次性读入内存。
- **换行与编码**：跨平台换行符、UTF-8 BOM 问题。

## 落地要点（实践）

- 写前备份或 git 快照，便于回滚。
- 对 `.env`、密钥文件默认不可读或脱敏显示。
- 合并冲突时提示人类。

## 常见坑

- 相对路径逃逸（`../../etc/passwd`）。
- 并发写同一文件无锁损坏。

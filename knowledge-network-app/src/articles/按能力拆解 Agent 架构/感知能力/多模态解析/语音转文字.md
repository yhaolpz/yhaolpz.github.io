# 语音转文字

## 一句话定义

把语音信号转为文本（ASR），并可附带时间戳、说话人分离等元数据，供下游对话与记忆使用。

## 先理解什么（入门）

语音输入在会议记录、客服、车载等场景很常见。ASR 输出质量受**采样率、噪声、口音、领域词**影响；Agent 侧通常还要做**标点与分段**。

## 再理解什么（进阶）

- **流式 vs 批式**：实时上屏用流式；高精度归档用批式整句解码。
- **热词与自定义词表**：产品名、人名、内部缩写必须配置，否则错误会传导到规划层。
- **说话人分离（diarization）**：多人会议要先分说话人再进摘要或任务抽取。

## 落地要点（实践）

- 明确语言与方言；多语言会议要检测语言切换。
- 保存 `word-level` 时间戳便于回放定位。
- ASR 置信度低片段应标红或触发人工确认。

## 常见坑

- 把会议长录音一次性转写不设分段，后处理极慢且难对齐行动项。
- 未做敏感词过滤导致隐私进日志。

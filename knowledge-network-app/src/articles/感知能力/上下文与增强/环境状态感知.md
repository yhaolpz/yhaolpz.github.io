# 环境状态感知

## 一句话定义

把运行环境（浏览器 DOM、操作系统、游戏状态、仓库文件树等）编码成模型可消费的**状态摘要**，支撑下一步决策。

## 先理解什么（入门）

Agent 不是真「看见」屏幕：它看到的是你提供的**文本化/图文化快照**。状态越忠实、越紧凑，规划与执行越稳。

## 再理解什么（进阶）

- **可观测性粒度**：全量 HTML 往往太大，需要 XPath/CSS 选择器提取关键节点。
- **差分**：相邻两步只传 diff，可显著省 token。
- **延迟**：状态在传输途中可能已变，要有版本号或时间戳。

## 落地要点（实践）

- 为 UI Agent 定义「可行动元素」列表（按钮、输入框）与坐标/选择器。
- 对敏感界面打码后再进模型。
- 状态 + 最近 k 步动作一起输入，减少马尔可夫假设带来的错误。

## 常见坑

- 把整页无障碍树原样粘贴，噪声淹没有效控件。
- 忽略不可见但重要的状态（权限、网络不可达）。

# 系统提示词

## 一句话定义

在对话开始时注入的**高优先级指令**，用于定义角色、边界、输出格式与安全策略。

## 先理解什么（入门）

系统提示（system prompt）通常比用户消息更稳定，适合写「你是谁、能做什么、不能做什么、默认输出结构」。很多 Agent 事故来自**系统提示过长或互相覆盖**。

## 再理解什么（进阶）

- **与开发者消息区分**：部分 API 区分 developer vs system，用于多租户隔离策略。
- **可测试性**：系统提示应像代码一样版本化、评审、回归测试（输入攻击样例）。
- **最小权限**：只给完成任务所需的能力描述，减少被越狱后的攻击面。

## 落地要点（实践）

- 明确禁止项：不得泄露密钥、不得执行未授权写操作等。
- 固定输出 schema（JSON/XML）时，把字段说明写清并给示例。
- 变更要走 code review，避免线上热改失控。

## 常见坑

- 把业务逻辑全部写进系统提示，难以维护与复用。
- 多语言混写导致模型忽略后半段约束。

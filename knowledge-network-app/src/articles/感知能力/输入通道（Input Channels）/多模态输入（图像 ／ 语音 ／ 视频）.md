# 多模态输入（图像 / 语音 / 视频）

## 一句话定义

把图像、语音、视频等原始信号转成可控的中间表示，再进入上下文与推理链路

## 关键要点

- 先做中间表示：OCR 文本、布局结构、时间戳、关键帧、说话人分离
- 分层保留：原始媒体 + 抽取文本 + 元数据
- 只把必要片段送进模型，控制 token 与噪声

## 最小示例

```text
输入：一张发票截图
中间表示：OCR 文本 + 关键字段（金额/日期/抬头）+ 置信度
输出：结构化 JSON + 异常提示
```

## 常见坑

- 直接把整段视频转写/全量 OCR 塞进上下文导致预算爆炸
- 不做置信度与异常处理导致错误传播

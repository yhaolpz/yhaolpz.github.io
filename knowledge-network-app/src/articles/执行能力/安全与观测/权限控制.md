# 权限控制

## 一句话定义

确保 Agent 及其工具**只能访问被授权的资源**（数据、API、系统命令），是安全底线而非可选增强。

## 先理解什么（入门）

权限模型：RBAC/ABAC、OAuth scope、行级安全（RLS）。Agent 继承调用者身份或使用服务账号，两者策略不同。

## 再理解什么（进阶）

- **最小权限**：默认拒绝，按任务临时授予短期凭证（STS）。
- **工具级**：每个工具声明所需权限，运行时校验。
- **审计**：谁在何时通过 Agent 访问了什么。

## 落地要点（实践）

- 工具层统一鉴权中间件，避免每个 handler 复制粘贴。
- 对跨租户 id 做强制过滤。
- 定期权限回收与访问评审。

## 常见坑

- 把 admin token 注入系统提示「方便调试」遗留到生产。
- LLM 被诱导越权调用工具。

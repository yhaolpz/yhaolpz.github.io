# 日志

## 一句话定义

按时间顺序记录**结构化事件**，支撑排障、审计与行为分析，是观测三角（logs/metrics/traces）之一。

## 先理解什么（入门）

Agent 日志应包含：session_id、message_id、tool、latency、错误码、模型版本。避免把密钥写进 info 级别。

## 再理解什么（进阶）

- **关联**：trace_id + span_id 串起分布式日志。
- **采样与分级**：debug 详、prod 简。
- **不可抵赖**：关键操作 append-only 存储。

## 落地要点（实践）

- JSON 行日志便于 ELK/Datadog 查询。
- 对长 prompt/response 存对象存储，日志只存 hash 与指针。
- 设定保留周期符合合规。

## 常见坑

- 日志量过大拖垮集群。
- 多线程日志乱序未带时间戳与序号。

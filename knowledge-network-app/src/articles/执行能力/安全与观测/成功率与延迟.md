# 成功率与延迟

## 一句话定义

用 **SLO/SLI** 度量 Agent 是否「好用」：任务成功率、首 token 延迟、工具错误率等，是持续改进的数据基础。

## 先理解什么（入门）

没有指标就无法优化。先把「什么叫任务成功」定义清楚：用户点赞、自动评测通过、还是业务工单关闭。

## 再理解什么（进阶）

- **分桶**：按场景、模型、租户拆分，避免平均掩盖问题。
- **滞后指标 vs 领先指标**：成功率滞后；队列深度、429 率是领先信号。
- **实验**：灰度发布与 A/B 对比必须控制变量。

## 落地要点（实践）

- 仪表盘展示 p50/p95/p99 延迟。
- 对失败聚类根因标签（超时、权限、模型胡编）。
- 与 on-call 告警阈值联动。

## 常见坑

- 只盯模型 loss 不看业务成功。
- 指标口径频繁改导致历史不可比。

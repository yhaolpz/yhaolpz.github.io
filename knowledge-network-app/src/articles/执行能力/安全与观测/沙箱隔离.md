# 沙箱隔离

## 一句话定义

在**部署与网络层**隔离 Agent 运行环境（独立 VPC、namespace、egress 控制），与代码沙箱互补，防止横向移动。

## 先理解什么（入门）

代码沙箱限制进程能力；部署沙箱限制「能连哪些内网、能访问哪些密钥」。两者叠加才是纵深防御。

## 再理解什么（进阶）

- **egress proxy**：所有出站经审计代理。
- **密钥管理**：KMS/Vault 动态下发短期凭证。
- **供应链**：镜像签名、SBOM、依赖漏洞扫描。

## 落地要点（实践）

- 生产与沙箱环境账号完全隔离。
- 默认无内网访问，按应用白名单开放。
- 定期渗透测试与红队演练。

## 常见坑

- 沙箱内仍可 DNS 反弹或 metadata 服务取凭证（云厂商特性需关）。
- 隔离过严导致合法工具不可用，倒逼用户绕过。

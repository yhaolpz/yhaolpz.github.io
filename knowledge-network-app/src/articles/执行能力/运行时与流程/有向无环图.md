# 有向无环图

## 一句话定义

用 **DAG** 表示任务依赖：边表示先后约束，无环保证拓扑排序存在，可并行执行无依赖节点。

## 先理解什么（入门）

DAG 是并行与缓存的基础结构。构建 Agent 工作流时，把「可并行读」与「必须顺序写」拆开能显著降延迟。

## 再理解什么（进阶）

- **动态扩图**：运行中发现新依赖要插入节点与边，需检测环。
- **关键路径**：最长路径决定最短 wall time，可优先优化。
- **与 LangGraph**：图执行 + 条件边 + 循环（实际可能是 cyclic graph，DAG 是其特例）。

## 落地要点（实践）

- 用成熟图库或工作流引擎持久化图定义。
- 对每条边记录数据契约（上游输出字段 = 下游输入）。
- 压测并行度对下游 QPS 影响。

## 常见坑

- 隐藏环（互相等待锁）导致死锁。
- 并行写同一资源无并发控制。

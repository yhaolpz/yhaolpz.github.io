# 浏览器自动化

## 一句话定义

通过驱动真实或 headless 浏览器完成**点击、输入、抓取 DOM** 等操作，是 Web Agent 的主要执行面。

## 先理解什么（入门）

典型栈：Playwright / Puppeteer / Selenium。Agent 需把「要做什么」翻译成选择器、等待条件与断言。

## 再理解什么（进阶）

- **稳定性**：显式等待元素而非 sleep；处理动态加载与 shadow DOM。
- **反自动化**：验证码、指纹检测需要合规方案（人审、官方 API）。
- **可观测**：录屏、HAR、trace viewer。

## 落地要点（实践）

- 在无头与有头模式间可切换调试。
- 对多标签页与弹窗建立状态机。
- 敏感操作前二次确认。

## 常见坑

- 选择器依赖易变 class，升级即挂。
- 未限制导航域名导致 SSRF 风险。

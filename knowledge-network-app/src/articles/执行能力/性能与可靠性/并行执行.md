# 并行执行

## 一句话定义

**同时**运行多个无依赖子任务（多线程/多进程/异步 I/O），缩短 wall time，是执行层性能优化的关键手段。

## 先理解什么（入门）

只读任务天然可并行；写任务需锁或分区。Agent 里常见并行：多源检索、多 API 校验、多文件处理。

## 再理解什么（进阶）

- **并发上限**：防止把向量库或 LLM 并发打满触发全站 429。
- **取消传播**：父任务取消时子任务也要停。
- **结果合并**：注意无序完成时的归并策略。

## 落地要点（实践）

- 用结构化并发（asyncio、Promise.all）并设 per-task 超时。
- 监控线程池队列深度。
- 对 GPU 任务串行或限流。

## 常见坑

- 共享可变结构无锁数据竞争。
- 并行度超过下游容量导致全员失败。

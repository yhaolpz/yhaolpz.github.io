# 插件系统

## 一句话定义

用**可插拔模块**扩展 Agent 能力：每个插件提供工具、资源与生命周期钩子，便于第三方或团队内并行开发。

## 先理解什么（入门）

插件系统类似 VS Code 扩展：发现、安装、启用、沙箱权限、版本兼容。对 Agent 平台可降低核心代码膨胀。

## 再理解什么（进阶）

- **隔离**：插件崩溃不能拖垮宿主；资源配额限制 CPU/内存/网络。
- **Manifest**：声明权限、入口、schema 版本。
- **与 MCP**：可把 MCP server 当作一类远程插件。

## 落地要点（实践）

- 插件 API  semver 与迁移指南。
- 审核上架流程（安全扫描 + 人工抽检）。
- 提供本地调试 harness。

## 常见坑

- 插件间全局单例冲突。
- 动态加载未签名代码导致供应链攻击。

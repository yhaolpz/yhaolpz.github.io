# API调用

## 一句话定义

通过 HTTP/gRPC 等协议访问**远程服务**，把 Agent 决策落到真实业务系统（查询、下单、配置变更等）。

## 先理解什么（入门）

与本地函数相比，API 有网络延迟、认证、分页、幂等等现实约束。Agent 侧通常把 OpenAPI 规范转成工具描述。

## 再理解什么（进阶）

- **OAuth / mTLS / API Key**：凭证轮换与最小权限。
- **重试与退避**：429/503 的处理策略。
- **分页与游标**：防止一次拉全表。

## 落地要点（实践）

- 用生成的类型安全客户端（OpenAPI Generator 等）。
- 在工具层统一超时、日志、指标。
- 对写操作强制传入幂等键或业务流水号。

## 常见坑

- 把生产密钥放进 prompt 或日志。
- 未限制调用频率导致把下游打挂。

# 重试与再规划

## 一句话定义

当工具失败或结果不满足条件时，**有限次重试**同一动作或**回到规划层**生成新策略，是可靠 Agent 的必备闭环。

## 先理解什么（入门）

重试解决瞬时故障（网络抖动、429）；再规划解决策略错误（调错工具、参数逻辑错）。二者要区分，避免死循环重试。

## 再理解什么（进阶）

- **指数退避**：对限流友好。
- **幂等键**：重试写操作防重复提交。
- **再规划预算**：每日最多 N 次全量 replan，防止成本失控。

## 落地要点（实践）

- 错误分类表：可重试 / 不可重试 / 需人介入。
- 记录每次重试的 `attempt_id` 与根因标签。
- 再规划时附带上次失败摘要，避免重复踩坑。

## 常见坑

- 对 4xx 业务错误无脑重试。
- replan 不携带观测，模型凭空改方案。

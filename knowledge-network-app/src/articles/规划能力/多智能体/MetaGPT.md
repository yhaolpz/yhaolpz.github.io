# MetaGPT

## 一句话定义

一种**角色化多智能体软件公司**范式：模拟 PM、架构师、工程师等角色分工协作生成代码与文档（开源框架/方法论代表）。

## 先理解什么（入门）

MetaGPT 强调用结构化输出（PRD、设计、接口）约束各角色，减少「各说各话」。适合教学「多 Agent 如何拆职责」。

## 再理解什么（进阶）

- **与真实团队流程对齐**：评审、CI、测试仍要在工程层落地。
- **成本**：多轮多角色调用 token 成本高，需要缓存中间件与复用。
- **可控性**：对关键输出保留人类 gate。

## 落地要点（实践）

- 先跑官方 demo，再替换为自己的工具链。
- 记录每角色 prompt 版本与输出 schema。

## 常见坑

- 角色过多导致协调开销大于收益。
- 生成代码未跑测试就合并。

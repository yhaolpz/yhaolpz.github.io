# 通信协议

## 一句话定义

多 Agent 之间交换消息的**格式、顺序、可靠性语义**（同步/异步、幂等、加密），是多智能体系统可维护性的基石。

## 先理解什么（入门）

最小协议包含：发送方、接收方、消息类型、payload schema、相关 id（session、trace）。可用消息队列、RPC 或内存事件总线实现。

## 再理解什么（进阶）

- **黑板模式 vs 点对点**：黑板适合共享状态少的协作；点对点适合强流水线。
- **版本演进**：schema 向后兼容策略。
- **与 MCP**：Model Context Protocol 也可视为模型与工具世界的通信标准之一。

## 落地要点（实践）

- 所有跨 Agent 消息走同一 tracing id。
- 定义心跳与超时，防止僵尸子 Agent。
- 对 PII 加密与最小暴露。

## 常见坑

- 无消息上限导致广播风暴。
- 无顺序保证时假设了顺序，出现竞态。

# 知识网络首页（Desktop-first）页面设计说明

## 1) Layout
- 布局策略：三栏 Hybrid（CSS Grid 为主 + 内部 Flex）。
- 网格建议：`grid-template-columns: 320px 1fr 360px;` 中间图谱自适应占最大面积；左右栏可折叠。
- 间距与对齐：全局 8px spacing scale；容器左右 padding 16–24px；卡片圆角 12px。
- 响应式（可选）：
  - <= 1024px：左侧筛选折叠为抽屉（Drawer），右侧详情变为底部抽屉（Bottom Sheet）。

## 2) Meta Information
- Title：知识网络
- Description：通过图谱探索知识点与关系，并按多维度筛选聚焦主题。
- Open Graph：
  - og:title = 知识网络
  - og:description = 图谱探索 + 多维度筛选
  - og:type = website

## 3) Global Styles（Design Tokens）
- Background：`--bg: #0B1020`（深色）或 `#F7F8FA`（浅色，二选一原型即可）
- Surface/Card：`--surface: rgba(255,255,255,0.06)`（深色）/ `#FFFFFF`（浅色）
- Text：主文本 `--text-1`、次级 `--text-2`；保证对比度
- Accent：`--accent: #4F7DFF`（选中/高亮）
- 节点状态：
  - 默认：中性灰/蓝
  - Hover：描边+轻微发光（box-shadow/outline）
  - Selected：加粗描边 + 邻居节点与边高亮
- 按钮：Primary（accent 实底），Secondary（描边/幽灵按钮），Hover 使用 150ms ease-out
- 字体层级：H1 20/24、H2 16/20、Body 14/20、Caption 12/16

## 4) Page Structure
- 顶部：固定 Top Bar（高度 56px）
- 主体：三栏内容区
  - Left：多维度筛选
  - Center：图谱主视图（页面视觉重心，占比更大）
  - Right：节点详情面板

## 5) Sections & Components

### 5.1 Top Bar
- 左侧：产品名「知识网络」
- 中间：搜索框（Placeholder：输入“具体内容词”搜索）
  - 输入联想：匹配节点 `term`（可选）
  - Enter/点击结果：定位并选中节点
- 右侧：
  - 「重置视图」：恢复默认缩放/中心点
  - 「清空筛选」：清空全部维度选择

### 5.2 Left Panel：多维度筛选
- 标题：筛选
- 维度分组（Accordion 结构，默认展开前 1–2 个最常用维度，如“组成元素”）：
  - 每个维度 = 一组多选项（Checkbox list + 可选搜索）
  - 顶部展示已选项 Chips（可单独移除）
- 底部：当前命中统计（节点数/边数）

### 5.3 Center：图谱主视图（核心）
- 画布：占据中心列全部可用高度；顶部留出 8–12px 给状态条（如“已应用 3 个筛选”）。
- 交互：
  - 鼠标滚轮缩放、拖拽平移
  - 单击节点：选中并打开右侧详情
  - Hover 节点：仅高亮一跳邻居（边加粗、非相关元素降低透明度）
- 节点呈现规则（关键约束）：
  - 标签显示：节点 `term`（具体内容词），不展示抽象分类名
  - 可选视觉映射：颜色/形状映射到某个维度（如“组成元素”）的取值
- 图例（Legend）：右下角悬浮卡片
  - 展示颜色/形状与维度取值的对应关系

### 5.4 Right Panel：节点详情
- 空状态：提示“点击节点查看详情”
- 选中状态内容：
  - Header：内容词标题（term）+ 复制按钮（可选）
  - 摘要：summary
  - 维度信息：以 Key-Value 列表展示（维度名：取值若干）
  - 相关节点：列表（显示相关节点 term + 关系类型），点击可切换选中
  - 操作：
    - 「仅看子图」：将视图收敛到当前节点及一跳邻居
    - 「返回全图」：恢复到筛选后的全量子图

## 6) Interaction States & Transitions
- 面板开合：200ms ease-in-out（transform/width）
- 图谱高亮：150ms 透明度与描边过渡
- 加载态：图谱区域显示 Skeleton/Spinner + “正在加载图谱数据”文案

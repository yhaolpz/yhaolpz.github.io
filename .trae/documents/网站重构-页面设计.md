# 网站重构（Desktop-first）页面设计说明

## 1) Layout
- 布局策略：单页纵向分区（Top Bar + 内容分区 + Footer）。
- 内容宽度：`max-width: 1040px`，居中；左右 padding `20px`（移动端）/`24px`（桌面）。
- 间距系统：8px spacing scale；分区上下间距 48–72px。
- 响应式：
  - <= 768px：Tab 纵向排列；关系示意从横向箭头改为纵向堆叠。

## 2) Meta Information
- Title：能力体系
- Description：白色极简单页：四能力关系说明 + Tab 切换 + Accordion 知识点列表。

## 3) Global Styles（Design Tokens）
- Theme：白色极简
- Background：`#FFFFFF`
- Border：`#E4E4E7`（zinc-200）
- Text：主 `#18181B`（zinc-900），次 `#52525B`（zinc-600）
- Accent：近黑 `#18181B`（用于选中态与强调线条）
- 圆角：16–24（卡片/分组）
- 动效：150–200ms ease-out（hover 与展开/收起）

## 4) Page Structure
- 顶部：Sticky Top Bar（高度 56px）
  - 左侧：站点名（回到顶部）
  - 右侧：锚点链接（能力关系 / 知识点）
- 主体：
  - Hero：一句话讲清四能力闭环
  - 能力关系：四能力简介卡片 + 闭环示意
  - 知识点：Tab 切换能力 + Accordion 展开分组
- Footer：轻量分割线 + 版权

## 5) Sections & Components

### 5.1 Top Bar
- 站点名：文本链接 `#top`
- 锚点导航：`#relationship`、`#knowledge`
- 视觉：白底半透明 + 轻边框 + blur（保持现代感且不花哨）

### 5.2 四能力关系说明区
- 四能力卡片：每张卡 3 行信息（名称/一句话/简述）。
- 闭环示意：四块信息卡 + 箭头；下方补一条“反馈闭环”说明。
- 交互：无复杂交互。

### 5.3 能力 Tab + 知识点 Accordion
- Tab：4 个能力；选中态用描边加深 + 底部 2px 指示条。
- 切换：点击 Tab 立即切换下方内容。
- Accordion：按分组组织知识点；默认展开第一个分组；一次只展开一个分组。

## 6) Interaction States & Transitions
- Hover：按钮/卡片背景轻微变灰（zinc-50）。
- Accordion：展开时出现分割线与内容区；Chevron 旋转 180°。
